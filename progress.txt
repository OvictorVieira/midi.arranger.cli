## Codebase Patterns
- Harness CLI usage errors use exit code 64; recognized but not-yet-implemented harness capabilities use exit code 69 so tests can distinguish parsing from dispatch.
- Run the project test suite with `python3 -m pytest`; on this machine `python` resolves to Python 2.7.
- Harness tests mock AI CLIs by putting fake binaries first on `PATH` and using `MOCK_LOG` to assert argv/stdin; never call real agent CLIs from tests.
- Agent output inspection state lives in `.midiarranger/last-agent-output.txt`; the harness writes the combined stdout/stderr stream there while echoing it to the user.
- `--list-models` must query installed CLIs and parse their live output; do not add baked-in model tables. Tests should isolate `PATH` and `HOME` so real local CLIs do not affect assertions.
- Reusable AI CLI mocks live in `tests/harness/fixtures/bin/`; harness tests copy them into a temp `PATH` and assert `MOCK_LOG` blocks for `ARG_*`, `STDIN`, and normalized `PROMPT`.
